# Resume Bullet Points
## Business Sales & Performance Analytics System

Here are **4 high-impact, truthful, and interview-defensible resume bullet points** tailored for Computer Science students targeting Data Analyst, Python Developer, and entry-level Data/Software Engineering roles.

---

### Option 1: Data Analyst Focus

- **Engineered an end-to-end sales analytics pipeline** in Python and SQL, processing 7,500+ raw transactions across 8 regional branches; automated data validation, deduplication, and financial metric calculations (`net_sales`, `AOV`).
- **Designed a 3NF relational database schema** in PostgreSQL/SQLite and authored 15+ analytical SQL queries utilizing CTEs, window functions (`RANK`, `LAG`), and multi-table JOINs to evaluate monthly revenue trends and branch performance.
- **Constructed a 3-page interactive Power BI dashboard** featuring DAX time-intelligence measures (`MoM Revenue Growth %`), interactive slicers, and statistical anomaly detection (IQR method) to highlight high-value sales outliers.
- **Automated pipeline logging and reporting** with Python (`logging`, `openpyxl`), generating structured multi-tab Excel executive performance summaries and implementing `pytest` unit tests for pipeline reliability.

---

### Option 2: Python / Software Developer Focus

- **Developed a modular Python data pipeline** (`pandas`, `numpy`, `SQLAlchemy`) that ingests raw business datasets, cleans 380+ intentional data quality flaws (missing values, bad dates, duplicate records), and populates a relational database.
- **Implemented statistical anomaly detection and sales forecasting** modules using `scikit-learn` (Linear Regression) and rolling moving averages to estimate upcoming 3-month revenue trends based on historical data.
- **Created a 3NF normalized star schema database** using DDL scripts in SQL; optimized query execution speeds by indexing key date, branch, and product foreign keys.
- **Maintained robust software practices** including structured logging, environment-based configuration management (`python-dotenv`), `pytest` unit testing, and GitHub documentation with Mermaid architecture diagrams.

---

### Concise One-Liner (For Summary / Skills Section)

> **Business Sales Analytics System (Python, SQL, PostgreSQL, Power BI, pandas, pytest)**: Developed an end-to-end data pipeline processing 7,500+ sales transactions, built a 3NF relational database with advanced window function SQL queries, and authored a 3-page Power BI executive dashboard with statistical anomaly detection.
